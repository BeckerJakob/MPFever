MPFever - Changelog
===================

0.1.1-experimental - synchronisation fixes
  - Random numbers of the game mechanics (loan offers, contracts, events) are now
    identical in every game: no more divergence of loans after a few minutes.
  - False alarms removed from the state comparison (internal engine counters), which
    caused needless resynchronisations at the start of a session.
  - No more speed request loop after a resynchronisation.
  - Notification sounds are no longer played twice.
  - Constructions from a previous session are no longer sent again at startup.
  - Lines: stops can be added in the line editor again (results of an earlier
    session no longer hide the new ones); lines and every other action now work
    while the game is paused, on every player's side.
  - Removing a stop with the bulldozer is replicated (the stop used to stay on the
    other players' maps).
  - Fewer interruptions: a slight drift of the engine's own simulation (vehicle
    positions, passengers, town statistics) is reloaded only if it lasts 5 minutes;
    real differences (roads, stops, lines, buildings, finances) still trigger an
    immediate resynchronisation.
  - Root cause of the slow drift found and fixed: on processors with 8 threads or
    more, the engine updates the game scripts (towns, loans, industries...) in
    parallel, in an order that depends on thread timing. The native module now gives
    them their own pool with one worker, as the engine itself does on smaller
    processors. Only the scripts' update is affected: the simulation, the rendering
    and the loading keep every core. Result in testing: 7 minutes at x4 without a
    single difference, and the same speed as before.
  - The game's speed request at startup no longer floods the launcher log.

0.1.0-experimental - first public test version
  - Cooperative multiplayer in one shared company, connection by IP address.
  - Synchronisation of the game's construction tools (roads, tracks, joins in the
    middle of a road, upgrades, stops including on tram tracks, stations, depots,
    buildings, bulldozer), vehicle purchases, lines, assignments, speed and pause.
  - Host authority: state comparison every 10 seconds (money, loans, company, contracts,
    towns, industries, cargo, vehicles, roads), automatic money correction, automatic
    resynchronisation from the host's savegame (about 20 seconds).
  - Deterministic game mechanics: contracts, loans, weather and industry events are
    the same in every game.
  - Launcher in English and French (follows the Windows language).
  - No process injection: the native module is a winhttp.dll the game loads by itself.
  - Full source code published, with build instructions.
